# Purpose

This skill starts every implementation session.

Its objective is to fully understand the project before making any changes.

This skill MUST NOT write or modify code.

---

# Workflow

## Step 1

Read:

docs/README.md

Follow the reading order exactly.

---

## Step 2

Read every required document in sequence until you understand:

- Product
- Business requirements
- Architecture
- Technology stack
- Documentation precedence
- Engineering rules
- Current project state
- Previous implementation session

---

## Step 3

Determine the next roadmap task.

Read every document required for that roadmap task.

---

## Step 4

Produce the following report.

# Current Understanding

Summarize your understanding.

# Roadmap Status

- Current task
- Previous task
- Next task

# Scope

Clearly define:

IN SCOPE

OUT OF SCOPE

# Files

Files to create

Files to modify

# Assumptions

List every assumption.

# Risks

List implementation risks.

# Questions

List unanswered questions.

# Implementation Plan

Describe implementation step by step.

Do not skip implementation details.

# Acceptance Criteria

Describe exactly how success will be verified.

---

# Stop

Wait for explicit user approval.

Do not modify any file.
